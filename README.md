# Maths 7 Lab

Trang ôn tập Toán 7 (theo sách Cambridge Lower Secondary Mathematics 7): lí thuyết trực quan, bài tập chấm điểm, phần mở rộng, bài đọc và nghe tiếng Anh, chạm để dịch từ, tạo đề thi.

Mở trang: https://aivietnam-aio-ductam.github.io/maths7-lab/

Trang tĩnh (HTML/CSS/JS), không cần cài đặt. Chạy trên máy: mở `index.html`.
Đây là trang ôn tập cá nhân, không phải sản phẩm chính thức của Cambridge.
